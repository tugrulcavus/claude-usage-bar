How it works

It reads Claude's own usage numbers

No token to paste. Usage Bar uses the login Claude Code already has, and asks Claude's usage API for your exact 5-hour and weekly numbers — nothing else.

You press Connect

Off by default — a fresh install reads nothing. Press Connect and it uses the token Claude Code already stores in your Keychain — silently, no password prompt. Disconnect any time.

→

Usage Bar asks Claude

It calls Claude's official usage endpoint as Claude Code does and reads only your 5-hour + weekly numbers — the same as the /usage screen. Reading never spends quota.

→

You glance

The menu-bar glyph and popover stay current while you work, and warn you before a window runs out.

Only Claude, only your usage. The app talks to nothing but Claude's official API, authenticated with your existing Claude Code login (read from the macOS Keychain) — no analytics SDK, no account, no server of mine. Once a day it also checks this project's GitHub release for a newer build and adds +1 to an anonymous per-day install counter (that count is the only usage signal there is — nothing identifies your machine); both stop the moment you switch update checks off in Settings. It's otherwise used solely to read your usage numbers. Note: this uses an undocumented endpoint, and Anthropic's ToS restricts these tokens to Claude Code / Claude.ai — third-party use is a gray area, so use at your own discretion; it may break if Anthropic tightens enforcement.

↓ Download for macOS
  1. Open the downloaded ClaudeUsageBar.dmg.
  2. Drag the app onto the Applications shortcut beside it.
  3. Open it from Applications — then look at the top right of your screen. It's a menu-bar app: no Dock icon, no window.
  4. Click the gauge and press Connect. Until you do, it reads nothing at all.

Prefer a zip, or want an older build? Everything is on Releases. Updates arrive in the app itself — one click, no re-download.
